# Global multiplicity view (P7) - 2026-11-26

Generated by `uv run astra multiplicity` (`src/astra/research/multiplicity.py`); tables in
`data/reports/research/multiplicity*.{md,parquet}`. **Descriptive re-assessment: nothing was re-run, no
record was changed, and no registered verdict is altered.** It answers one question: which results would
still stand if the whole programme, not just each family, were treated as one set of tests?

## Inputs
- 763 experiment records; 254 are *current*. The rest are superseded by a later run of the same cell
  (same hypothesis, subject and name), computed by `Tracker.status()` and never written into records.
- Primary tests come from an explicit registry (`PRIMARY_RULES`), one key per hypothesis family, fixed
  before computing the view. t statistics are converted to two-sided normal p-values.
  - H-PF-001's registered decision is a bootstrap CI with no p-value. Its pre-registered secondary
    Newey-West t on squared-return differences stands in for it.
  - Diagnostics (H-XM-000) and descriptive studies (H-MS-001/002) are excluded.
  - 15 current records carry no primary key (family summaries, H-ML-001 grid, H-MM-001). They are
    listed in `multiplicity_global_unmapped.parquet`.
- Each test is counted once (cell and family duplicates removed): **242 tests**.

## 2. Deflated Sharpe ratio
- **Curves:** 192 net strategy equity curves from current records. Benchmark and gross curves are excluded.
- **Deflation:** n_trials = 192, with the cross-trial variance of per-period Sharpe ratios.
- **Result:** only **3 curves have DSR > 0.95**:
  - H-VT-001 vol-managed EW India (annualized SR 1.39, DSR 0.998)
  - H-CS-001 12-1 momentum India (SR 1.26, DSR 0.992)
  - H-VT-001 vol-managed AAPL (SR 1.14, DSR 0.963)
- **Caveats:**
  - The India curves cover 2019-2026 on a survivorship-biased universe (today's large caps, KNOWN_ISSUES).
  - Mixing 252- and 365-day markets in one variance is an approximation.
  - DSR here is a screening statistic, not a new hypothesis test.

## 3. Calibration of stored out-of-sample probabilities
Brier skill is relative to the base-rate forecast. ECE uses 10 equal-count bins. A calibration slope
below 1 means over-confident predictions.

- **H-XM-002** (logistic, 13 instruments): Brier skill is negative for every instrument (-0.012 to -0.0004).
  - Slopes are -0.33 to 0.50, with ECE about 0.035-0.055.
  - The probabilities are worse than predicting the base rate and are badly over-confident.
  - This is consistent with the recorded inconclusive or rejected results.
- **H-MM-001:** every model has negative skill (-0.003 to -0.053). Adding fundamentals or macro makes
  calibration worse.
- **H-ML-003** (574k rows) and **H-ML-004** (892k rows): small positive skill.
  - H-ML-003: 0.0004 (logit) and 0.0007 (XGB). H-ML-004: 0.0038 and 0.0048.
  - Slopes 0.63-0.82: real but tiny signal, mildly over-confident. Probabilities should be shrunk
    before any position sizing uses them.
- Constant base-rate forecasts have undefined slopes (the reported values like -4.6 are meaningless).

## Limitations
- The primary-test registry is a judgement call per family; it is in code and reviewable.
- Tests within a family are correlated (shared data). BY covers arbitrary dependence and gives 24 vs 27.
- p-values from t statistics assume asymptotic normality.
